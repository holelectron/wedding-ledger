# 마음을 모아 · 축의금 정리

Windows에서 사용하는 축의금·식권 접수 프로그램입니다. 입력 내역을 자동 저장하고, 수식이 포함된 Excel 파일로 정산할 수 있습니다.

## 처음 설치하기

1. Python 3.11 이상을 설치합니다. 설치 화면에서 **Add python.exe to PATH**를 선택하세요.
2. GitHub의 **Code → Download ZIP**으로 내려받고 **압축을 모두 해제**합니다.
3. 쓰기 가능한 폴더에서 `setup.bat`을 실행합니다. 처음에는 인터넷 연결이 필요하며, 프로젝트 전용 `.venv`에 Pillow를 설치합니다.
4. 설치가 완료됐다는 안내를 확인하고 아무 키나 누르면 프로그램이 열립니다. 이후에는 `실행.vbs`를 더블 클릭하면 검정 콘솔 창 없이 실행됩니다.

`실행.bat`도 지원하지만 배치 파일 특성상 검정 창이 잠깐 보일 수 있습니다. 설치용 `setup.bat`은 진행 상황과 오류를 보여 주기 위해 콘솔을 사용합니다. 기존 PC의 `실행.lnk`는 해당 PC에서만 사용하는 바로가기입니다.

다른 PC로 옮길 때 `.venv`를 복사하지 말고 `setup.bat`을 다시 실행하세요.

## 접수와 정산

- 첫 줄에 **이름·금액·식권**을 입력합니다. Enter로 이름 → 금액 → 식권 → 등록 순서로 진행합니다.
- 금액은 **만원** 단위입니다. `2.5`는 25,000원, `100`은 1,000,000원입니다.
- 식권 기본값은 1장이며 0장 또는 여러 장을 기록할 수 있습니다.
- 구분·관계·전달 방법·접수 담당·메모도 기록합니다.
- 목록 순서는 이름 / 금액 / 식권 / 전달 방법 / 관계 / 구분 / 메모입니다. 데이터를 가운데 정렬로 표시합니다.
- 내역을 선택하고 **선택 수정** 또는 더블 클릭으로 수정합니다. 검색과 구분 필터를 사용할 수 있습니다.
- **전체 초기화**는 검색 조건에 관계없이 모든 내역을 지웁니다. 확인 후 삭제하며, 직전에 현재 DB 옆 `backups` 폴더에 백업합니다.
- **엑셀로 저장**은 바탕화면을 기본 위치로 전체 명부와 정산 요약을 `.xlsx` 파일에 저장합니다. 표시 단위는 만원, 숫자 형식은 일반입니다.
- 요약의 건수·금액·식권은 명부를 참조하는 `SUM`, `SUMIF`, `COUNTIF`, `COUNTA` 수식입니다. Excel에서 명부를 수정하거나 행을 추가하면 재계산됩니다.

## 데이터 저장 위치

처음 실행하면 프로그램 폴더에 `wedding.db`를 자동 생성합니다. **저장 위치 변경**에서 다른 폴더를 선택할 수 있습니다.

- 선택한 폴더에 `wedding.db`가 없으면 생성하고 현재 접수 내역을 복사합니다.
- 파일이 있으면 그 DB의 내역을 엽니다. 기존 파일은 보관합니다.
- 선택한 경로는 PC의 `settings.json`에 기억합니다.
- DB 백업·복원·복사 전에는 프로그램을 모두 종료하세요. 복원은 백업 DB를 원하는 데이터 폴더의 `wedding.db`로 복사한 뒤 해당 폴더를 선택하면 됩니다.

각 PC가 독립된 DB를 사용합니다. 여러 접수자가 하나의 파일을 네트워크·클라우드 동기화로 동시에 편집하는 방식은 지원하지 않습니다.

## 글꼴

설치된 글꼴 중 Pretendard → Noto Sans KR → 맑은 고딕 순서로 선택합니다. 별도 글꼴 설치 없이도 실행됩니다.

## 저장소에 포함하는 파일

`app.py`, `requirements.txt`, `setup.bat`, `실행.vbs`, `실행.bat`, `README.md`, `.gitignore`만 배포합니다. 접수 내역·엑셀·백업·개인 설정·PC 전용 바로가기·가상 환경은 Git에서 제외합니다.

## 설치 창이 닫히거나 실행되지 않을 때

최신 `setup.bat`은 성공·실패 결과를 표시하고 키를 누르기 전에는 닫히지 않습니다. 먼저 ZIP 전체를 압축 해제한 뒤 실행하세요. 실패 시 프로그램 폴더의 `setup.log`에서 원인을 확인할 수 있습니다. 명령 프롬프트에서 `setup.bat --check`를 실행하면 설치·실행 환경만 점검합니다.
